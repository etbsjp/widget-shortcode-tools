# Shortcode Widget Tools

ウィジェットをショートコード化して、投稿本文や固定ページに埋め込めるプラグインです。

## できる事

1. **「設定 → 表示設定」の「デフォルト数」**で、ショートコード化するウィジェットの数（1〜5）を指定します。
2. 数を保存すると、**「外観 → ウィジェット」**に `[widget_shortcode_1 ws=1]` 〜 その数までのウィジェットエリアが追加されます。
3. 各エリアにウィジェットを配置し、対応するショートコード（例：`[widget_shortcode_1 ws=1]`）を投稿・固定ページの本文に貼り付けると、そのウィジェットが表示されます。

```
[widget_shortcode_1 ws=1]
[widget_shortcode_2 ws=2]
```

**表示するウィジェットを決めるのは `ws` の数字です**（ショートコード名の数字ではありません）。
`ws` を省略すると 1 とみなされるため、`[widget_shortcode_3]` はウィジェット1を表示します。
「外観 → ウィジェット」に表示されるエリア名がそのまま貼り付けられる形になっているので、
そちらをコピーしてお使いください。

## 注意事項

「デフォルト数」を減らすと、次の2つが同時に起きます。

- **本文に貼ってあるショートコードのうち、番号がデフォルト数を超えるものは変換されず、
  記述したままの文字列としてページに表示されます**（例：デフォルト数が2のとき
  `[widget_shortcode_3 ws=3]` はそのまま文字として出ます）。**訪問者に見えるのはこちらです。**
- それを超える番号のウィジェットエリアは「外観 → ウィジェット」から消え、そこに配置していた
  ウィジェットは同画面を開いた時点で**「使用停止中のウィジェット」へ移動します**。
  中身は残りますが、数を戻しても自動では元の位置に戻りません。

減らす前に、その番号のショートコードを本文から外してください。
