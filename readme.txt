ウィジェットをショートコード化して、投稿本文や固定ページに埋め込めるプラグインです。

== Description ==

ウィジェットをショートコードとして扱えるようにします。ウィジェットの数は「設定 → 表示設定」で 1〜5 の範囲で指定し、`[widget_shortcode_1 ws=1]` のように本文へ埋め込みます（数字は 1〜5）。

= 動作環境 =

WordPress・PHP のバージョン下限は設けていません。
